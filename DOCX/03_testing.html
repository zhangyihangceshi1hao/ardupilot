测试方式：光电吊舱 Guided 指点飞行指令源优先级

1. 测试环境

组件要求
飞控ArduCopter（AOIpilot 或 SITL）
地面站Mission Planner / QGC / MAVProxy
吊舱模拟第二个 MAVLink 连接（如 UDP 或额外串口），模拟吊舱发送 SET_POSITION_TARGET_GLOBAL_INT
参数设置GUID_EOIR_CHAN=吊舱通道号，GUID_EOIR_PRIO=1

2. 测试用例

TC-01：吊舱锁定后地面站被屏蔽

步骤操作预期结果
1飞控切换到 GUIDED 模式进入 GUIDED
2地面站发送 SET_POSITION_TARGET_GLOBAL_INT 让飞机飞向点 A飞机飞向点 A
3吊舱通道发送 SET_POSITION_TARGET_GLOBAL_INT 让飞机飞向点 B_guided_eoir_active 变为 true，飞机飞向点 B
4地面站再次发送 SET_POSITION_TARGET_GLOBAL_INT 让飞机飞向点 C指令被拒绝，飞机继续飞向点 B

TC-02：地面站发送重置命令收回控制

步骤操作预期结果
1接 TC-01，当前吊舱锁定中_guided_eoir_active = true
2地面站发送 MAV_CMD_GUIDED_SOURCE_PRIORITY(param1=0)_guided_eoir_active 变为 false
3地面站发送 SET_POSITION_TARGET_GLOBAL_INT 让飞机飞向点 C指令被接受，飞机飞向点 C

TC-03：吊舱重新抢占控制

步骤操作预期结果
1接 TC-02，当前 NORMAL 状态_guided_eoir_active = false
2吊舱通道发送 SET_POSITION_TARGET_GLOBAL_INT_guided_eoir_active 变为 true，指令被接受
3地面站发送 SET_POSITION_TARGET_GLOBAL_INT被拒绝

TC-04：功能禁用时行为不变

步骤操作预期结果
1设置 GUID_EOIR_PRIO=0功能禁用
2地面站发送 SET_POSITION_TARGET_GLOBAL_INT → 点 A飞向点 A
3吊舱发送 SET_POSITION_TARGET_GLOBAL_INT → 点 B飞向点 B（后发覆盖）
4地面站发送 SET_POSITION_TARGET_GLOBAL_INT → 点 C飞向点 C（行为与未修改前一致）

TC-05：非 GUIDED 模式不受影响

步骤操作预期结果
1飞控在 LOITER 模式—
2吊舱发送 SET_POSITION_TARGET_GLOBAL_INT被忽略（仅 GUIDED 模式才处理）
3切换到 GUIDED 模式后吊舱再发指令正常锁定

3. SITL 测试配置

# 启动 SITL
sim_vehicle.py -v Copter --console --map

# 添加第二个 MAVLink 连接模拟吊舱（UDP 14551）
# 在 MAVProxy 中：
output add 127.0.0.1:14551

# 设置参数
param set GUID_EOIR_CHAN 1    # 假设吊舱在 MAVLink 通道 1
param set GUID_EOIR_PRIO 1    # 启用吊舱优先级

# 切换 GUIDED 模式
mode guided

# 测试：分别从不同通道发送 guided 指令，验证优先级行为

4. 验收标准

#用例验收条件
1TC-01吊舱通道发送指令后，_guided_eoir_active 置 true，地面站指令被屏蔽
2TC-02地面站发送重置命令后，_guided_eoir_active 置 false，地面站指令恢复接受
3TC-03吊舱可随时发指令重新锁定
4TC-04禁用功能后行为与未修改前完全一致
5TC-05非 GUIDED 模式下功能不生效
6—无内存泄漏、无看门狗超时、不影响实时性
