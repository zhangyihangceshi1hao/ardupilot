实现方案：光电吊舱 Guided 指点飞行指令源优先级

1. 状态机设计

                        吊舱通道发送
                    SET_POSITION_TARGET_*
   ┌──────────┐  ──────────────────────►  ┌────────────────┐
   │          │                           │                │
   │  NORMAL  │                           │  EOIR_LOCKED   │
   │  (默认)  │                           │  (吊舱锁定)     │
   │          │ ◄───────────────────────  │                │
   └──────────┘    地面站发送              └────────────────┘
                    MAV_CMD_GUIDED_SOURCE_PRIORITY (param1=0)
  • NORMAL：所有 MAVLink 通道的指点飞行指令均接受
  • EOIR_LOCKED：仅接受吊舱通道的指令，其他通道（地面站）指令被拒绝

2. 新增 MAVLink 消息

属性值
消息名MAV_CMD_GUIDED_SOURCE_PRIORITY
消息 ID12923
字段action（uint8_t）：0 = RESET（地面站收回控制权），1 = EOIR_ACTIVE（启用吊舱优先）

定义文件：ArduCopter/common.xml（从 modules/mavlink/message_definitions/v1.0/common.xml 复制，并在 <messages> 块末尾追加）

<message id="12923" name="MAV_CMD_GUIDED_SOURCE_PRIORITY">
  <description>Set or reset guided mode control source priority.</description>
  <field type="uint8_t" name="action">Action: 0=Reset EO/IR priority, 1=Enable EO/IR priority.</field>
</message>

5. 核心判决逻辑

5.1 Copter.h — 新增枚举和成员

// 枚举定义在代码中（不在 MAVLink XML）
enum class GuidedSourcePriority : uint8_t {
    RESET  = 0,  // 清除吊舱锁定，地面站收回控制权
    EOIR_ACTIVE = 1,  // 启用吊舱优先级模式
};

// Copter 类新增成员
bool _guided_eoir_active;  // 吊舱是否已锁定控制权

bool guided_eoir_active() const { return _guided_eoir_active; }
void set_guided_eoir_active() { _guided_eoir_active = true; }
void reset_guided_eoir_active() { _guided_eoir_active = false; }

5.2 GCS_Mavlink.cpp — handle_message() 通道检查

在 SET_POSITION_TARGET_GLOBAL_INT / SET_POSITION_TARGET_LOCAL_NED / SET_ATTITUDE_TARGET 每个 case 的顶部、in_guided_mode() 检查之前插入：

if (copter.g2.guided_eoir_prio > 0) {
    if (chan == copter.g2.guided_eoir_chan) {
        copter.set_guided_eoir_active();   // 吊舱通道：锁定
    } else if (copter.guided_eoir_active()) {
        break;                              // 非吊舱通道 + 已锁定：拒绝
    }
}

5.3 GCS_Mavlink.cpp — handle_message() 新增消息处理

case MAVLINK_MSG_ID_MAV_CMD_GUIDED_SOURCE_PRIORITY: {
    mavlink_mav_cmd_guided_source_priority_t packet;
    mavlink_msg_mav_cmd_guided_source_priority_decode(&msg, &packet);
    if (packet.action == (uint8_t)GuidedSourcePriority::RESET) {
        copter.reset_guided_eoir_active();
        GCS_SEND_TEXT(MAV_SEVERITY_INFO, "EO/IR guided priority reset by GCS");
    } else if (packet.action == (uint8_t)GuidedSourcePriority::EOIR_ACTIVE) {
        copter.set_guided_eoir_active();
        GCS_SEND_TEXT(MAV_SEVERITY_INFO, "EO/IR guided priority enabled by GCS");
    }
    break;
}

6. 影响范围

方面影响
现有功能零影响 — 参数默认禁用，所有新增逻辑在 GUID_EOIR_PRIO=0 时完全旁路
内存+1 byte（bool _guided_eoir_active）
CPU每条 guided 指令额外 2 次整数比较 + 1 次布尔检查
消息流量仅在发送优先级重置命令时多一条 MAVLink 消息
