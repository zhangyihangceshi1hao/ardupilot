使用说明：光电吊舱 Guided 指点飞行指令源优先级

1. 功能概述

启用后，飞控在 GUIDED 模式下优先响应吊舱直连串口的指点飞行指令。一旦吊舱开始发送指令，地面站/数传通道的指令被屏蔽。地面站可通过发送 MAVLink 消息收回控制权。

2. 参数配置

2.1 确定吊舱的 MAVLink 通道号

SERIAL 端口MAVLink 通道典型用途
SERIAL0chan 0USB / 控制台
SERIAL1chan 1数传 1（通常接地面站）
SERIAL2chan 2数传 2
SERIAL3chan 3数传 3
SERIAL4chan 4数传 4（常接 companion computer 或吊舱）
SERIAL5chan 5数传 5
SERIAL6chan 6数传 6

2.2 设置参数

参数建议值说明
GUID_EOIR_CHAN吊舱所在 MAVLink 通道号例：SERIAL4=chan4，设为 4；0=禁用
GUID_EOIR_PRIO11=启用吊舱优先，0=禁用

3. 地面站操作

3.1 正常使用

地面站无需特殊操作。吊舱开始发指令后，地面站 guided 指令自动被屏蔽。

3.2 收回控制权（RESET）

当地面站需要主动接管时，发送 MAVLink 消息：

MAV_CMD_GUIDED_SOURCE_PRIORITY (msgid=12923)
  action = 0 (RESET)

发送后地面站指令立即恢复生效。

Mission Planner 操作：

  1. 打开 MAVLink 检查器 → 消息标签
  2. 找到消息 ID 12923（MAV_CMD_GUIDED_SOURCE_PRIORITY）
  3. action 字段填入 0
  4. 点击发送消息

3.3 启用吊舱优先级（ENABLE）

MAV_CMD_GUIDED_SOURCE_PRIORITY (msgid=12923)
  action = 1 (ENABLE)

4. 典型工作流程

阶段吊舱行为地面站行为控制权
初始无指令可能发指令地面站
吊舱锁定发送指点飞行指令指令被屏蔽吊舱
吊舱持续引导持续发指令指令持续被屏蔽吊舱
地面站接管停止发指令发送 RESET + 指点飞行指令地面站
吊舱重新抢占发送指点飞行指令指令被屏蔽吊舱

5. 注意事项

  • 功能仅在 GUIDED 模式下生效，其他飞行模式不受影响
  • GUID_EOIR_PRIO=0 时功能完全禁用，行为与修改前一致
  • 地面站收回控制权后，吊舱随时可通过再次发指令重新锁定
  • 若吊舱故障停止发指令，地面站需主动发送 RESET 消息才能接管（无自动超时恢复）
  • 编译前需用修改后的 common.xml 重新生成 MAVLink 头文件
